Contact: [dan@roadmaplabs.com.au](mailto:dan@roadmaplabs.com.au)

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

This is a Next.js app. Import the repo on Vercel and use the default framework settings — no extra config. To check the production build locally:

```bash
npm run build
npm start
```
