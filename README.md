# Roadmap Labs website

Public marketing site for [Roadmap Labs](https://roadmaplabs.com.au). Next.js App Router, ready for a Vercel preview.

This repository is the public site only.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

| Path | Status |
| --- | --- |
| `/` | Fold copy and selected-work mock-ups |
| `/projects` | Placeholder |
| `/projects/[slug]` | Placeholder |
| `/insights` | Placeholder |
| `/insights/[slug]` | Placeholder |
| `/about` | Placeholder |
